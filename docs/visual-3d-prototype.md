# Animated 3D map prototype

This is a candidate visual direction, not a locked North Star or a change to the current desktop release. The first experiment should make one selected camp feel alive while retaining the map's existing DOM controls, labels, keyboard path, and unit selection.

Use [Three.js](https://github.com/mrdoob/three.js) (MIT) as a viewport-sized layer beneath `MapStage`'s interactive elements. An orthographic camera can follow the current pan/zoom transform without replacing the repository layout or the source-derived unit model. Start with original procedural low-poly geometry: three distinct buildings and five role-coded units in one camp, with restrained idle/working/attention motion. Share geometries and materials, animate only visible units, clean up WebGL resources, respect reduced motion, and keep the existing 2D presentation as a fallback. Measure the representative 1920×1080 desktop view before extending the scene to more camps.

The current integration seams are `src/components/MapStage.tsx` for view state, `src/layout.ts` for world coordinates, and `src/components/Outpost.tsx` / `src/components/UnitFigure.tsx` for accessible hit targets. A `MapScene3D` should consume positioned bases plus view, viewport, and selection state; it should not own project data or agent actions.

An asset pack can follow once the first procedural scene proves the camera and interaction. [Kenney's Prototype Kit](https://kenney.nl/assets/prototype-kit) is marked CC0 and includes 3D variants; inspect the exact models and animation clips before use. [Babylon.js](https://github.com/BabylonJS/Babylon.js) (Apache 2.0) is a reasonable alternative if the map grows into a full 3D application. [Godot](https://godotengine.org/license/) (MIT) would introduce a separate WebAssembly application boundary. [Warzone 2100](https://github.com/Warzone2100/warzone2100) is useful as an RTS reference, but its native C++ engine and mixed asset licensing are not a drop-in web art source. Do not extract StarCraft models, textures, sounds, or branding; open-source RTS code does not grant rights to Blizzard assets.

Prototype acceptance: one camp aligns with the existing map while panning and zooming; selection, focus, and labels remain usable; the scene has a clear 2D/WebGL-unavailable fallback; reduced-motion behavior is deliberate; and remote K3s Chrome validation at 1920×1080 records visual quality and frame timing. Keep this out of the single-player functional release gate until a North Star is approved.
